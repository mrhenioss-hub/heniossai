## NEW: MISSION-CENTERED REINTERPRETATION — FORGET VS CODE, ANTIGRAVITY AS CLOSEST CONCEPTUAL REFERENCE, PRIMARY OBJECT MISSION NOT FILE, AI PRIMARY ACTOR, FILES SECONDARY TOOLS ONLY WHEN MISSION REQUIRES

### Source of Inspiration: Antigravity Philosophy Extracted Without Copying

Antigravity (from known industry analysis, not copied appearance) organizes work around Missions, not Files:

- **Work is a Mission, not a File Edit:** User says "Build JWT auth" → AI creates Mission with goal, plan (todos), required context, execution steps, expected artifacts. Files are touched as side effects of mission, not primary object.
- **AI is Primary Actor:** Timeline shows AI thinking, planning, tool calls, asking questions, requesting permissions. Human is supervisor/reviewer approving, not typist in editor.
- **Explicit Context & Plan:** Context chips (files, images, references) visible always in composer, Todo list with progress AnimatedNumber + TextReveal spring, not hidden in sidebar.
- **Artifacts Over Browsing:** Review tab with diff stats +45 -12 is primary output of mission, not file tree browsing. User reviews mission artifacts to decide accept/revert.
- **Execution Flow Observable:** Terminal logs, tool outputs, permission patterns, followup suggestions all visible in timeline and docks above composer, not separate bottom panel hidden.
- **Editor Secondary Tool:** Preview file content appears only when mission requires verification of a specific file touched, via existing layout.previewPanel.open() signal, then auto-hides after review. Not default open.
- **Command-Driven Mission Control:** mod+p palette fuzzy Commands/Missions/Sessions — search mission by title "auth-refactor" + relative time, not file by name.

**What we take for HeniossAI:** Mission-centric IA, explicit context/plan/artifacts, execution flow visibility, editor/terminal/preview as secondary conditional tools.

**What we DON'T take:** Antigravity's specific dark theme, layout measurements, component shapes. Original HeniossAI identity Precision Surface charcoal/paper + Cobalt accent remains.
